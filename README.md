🎮 Buzzer Showdown

Welcome to Buzzer Showdown, a multiplayer buzzer game designed to bring the excitement of TV game shows to your own game nights!

📥 Download & Play

This repository contains the official download and how-to-play page for Buzzer Showdown.

From this page, you can:

* Download Buzzer Showdown to get started.
* Learn how to play with instructions for hosts and players.
* Find out how to set up and run your own game.

🎯 How to Play

1. The host launches Buzzer Showdown on their computer.
2. Players join the game using their phones.
3. Everyone gets ready at their buzzers.
4. The host starts the game.
5. Buzz in and see who gets to answer first!

Perfect for game nights, quizzes and friendly competitions.
